## Getting Started

### Clone the repository

```bash
git clone https://github.com/Shivvani15/Shivani_Linux_CU26280050.git
cd Shivani_Linux_CU26280050
```

### Prerequisites

- A Linux system (Ubuntu / Debian / Fedora), a virtual machine, or **WSL** on Windows
- Bash shell (default on most distributions)

---

## How to Run

Give the script execute permission and run it:

```bash
chmod +x script_name.sh
./script_name.sh
```

Or run it directly with bash:

```bash
bash script_name.sh
```

Some scripts take input from the user or need command-line arguments. Check the comments at the top of each script for usage.
